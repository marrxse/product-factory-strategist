# Сценарий видео (до 10 минут)

Требование задания: сквозной путь демонстрационного проекта — **запрос, работа агента, варианты, стратегия, продолжение после перерыва**. Снимаем кусками по 1–3 минуты; долгие шаги ускоряем монтажом ×4–×8 с подписью реального времени.

Куски 1–3 снимаются на **новой задаче** (живой запуск), куски 4–6 — на **готовом демо** `projects/demo-antifraud` (полный путь уже пройден, ждать не нужно).

## Подготовка (10 минут)
- Режим «Не беспокоить»; закрыть лишние окна; шрифт в Claude Code крупнее (`Cmd` и `+`).
- Открыть заранее: README на GitHub, `projects/demo-antifraud/outputs/report.pdf`, `docs/DESCRIPTION.pdf`.
- Запись экрана: `Cmd + Shift + 5` → «Записать весь экран» → «Параметры» → включить микрофон.

## После записи — обязательно
- Новая задача из кусков 2–4 создала проект в `projects/` и сделала его активным. Если не доводите её до конца — не выкладывайте её в репозиторий и верните демо: `python3 sf.py use demo-antifraud`. Если доведёте до стратегии — это сильный третий пример «агент справляется с новыми задачами»; скажите агенту, и он проверит и оформит его.
- Не показывать в кадре личную почту, ключи и посторонние вкладки.
- Видео загрузить на YouTube / VK Видео / RuTube / Яндекс Диск с доступом по ссылке и проверить ссылку в окне инкогнито.
