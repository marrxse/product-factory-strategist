# Сценарий видео (до 10 минут)

Цель: показать сквозной путь — запрос → работа агента → варианты → стратегия → остановка и продолжение в новом чате → стоимость и проверки. Запись — Claude Code, экран с чатом и файлами. Длинные шаги ускорять монтажом (×4–×8) с подписью реального времени.

**Подготовка:** свежая копия репозитория; `python3 sf.py sync`; бриф в `examples/<пример>/brief.md` (бриф МегаФона по [DEMO_SWAP.md](DEMO_SWAP.md) или `examples/demo`). Готовый прогон для подстраховки — `projects/demo-antifraud`.

| Время | Что на экране | Что говорить |
|---|---|---|
| 0:00–0:40 | README, структура папки | «Это не программа, а папка: правила, навыки, знания, CLI. Открываем в Claude Code» |
| 0:40–1:40 | `начни по примеру examples/…` → агент задаёт 1–3 вопроса с вариантами по умолчанию; ворота 0 | «Агент спрашивает только то, что меняет следующий шаг» |
| 1:40–3:00 | Сбор: `sf.py fetch`, снимки в `sources/`, `evidence.csv` с цитатами; честные «не удалось открыть» | «Каждое сведение — источник, место, дата, дословная цитата» |
| 3:00–4:00 | Исследование: выводы `**C1.** … [E…]`, раздел «Чего мы не знаем»; **хук ловит число без источника** и агент исправляет | «Форму проверяет код — после каждой записи» |
| 4:00–5:20 | Варианты: 5 ставок, «оставить» и «закрыть», сильнейшие возражения от критика; quality-report; ворота 4 — выбор | «Критик не видел процесса и не защищает работу» |
| 5:20–6:00 | **Стоп.** Закрыть чат. Новый чат → «продолжи» → сводка: этап, сделано, дальше; повтор выполненного шага блокируется | «Состояние в файлах, не в памяти чата» |
| 6:00–7:30 | Стратегии: обещания О → возможности П, таблица согласованности; план проверки с порогами; decision-brief | «Обещания коммуникации опираются на продукт — это проверяется» |
| 7:30–8:30 | Пересмотр: `sf.py evidence revoke E…` → `sf.py revisit E…` → затронутые выводы; `revisit --stale` | «Новые данные — и агент знает, какие выводы пересмотреть» |
| 8:30–9:30 | `sf.py cost report`; `python3 -m unittest`; `sf.py validate --final`; eval: 12/14 против 6/14 у обычного чата | «Сколько стоило, и что мы честно не знаем» |
| 9:30–10:00 | LIMITATIONS: что не умеет | «Агент не заменяет эксперта — он делает работу проверяемой» |

**Не забыть:** показать реальное время по журналу; не показывать секреты и личные данные; если сайт недоступен во время записи — это нормальный кадр «агент честно фиксирует сбой».
