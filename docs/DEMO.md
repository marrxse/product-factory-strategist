# Видео (9:47)

**Смотреть:** [https://disk.yandex.ru/d/UKPb2TWtNKjlmQ](https://disk.yandex.ru/d/UKPb2TWtNKjlmQ) (Яндекс Диск, открывается без входа)

Видео показывает весь путь агента: запрос, самостоятельную работу, перерыв и продолжение, варианты, стратегию, работу после решения. Автор и голос — Бабкина Мария.

**Как смонтировано.** Пока агент работает, запись ускорена: в кадре зелёная плашка «ускорено ×N». Ответы агента и пролистывание результатов идут в обычном темпе, чтобы их можно было прочитать. Чтобы уложиться в 10 минут, длинные показы одной страницы сокращены.

- [projects/megafon-family](../projects/megafon-family) — тот же бриф, пройденный до конца (сцены 5–7).
- [projects/demo-antifraud](../projects/demo-antifraud) — второй пример: работа после решения (сцена 8).
