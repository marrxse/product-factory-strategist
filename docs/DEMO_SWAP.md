# Замена демо-брифа на бриф МегаФона (≈10 минут работы человека)

Агент не содержит ничего, зашитого под демо: вся специфика лежит в `examples/<пример>/`. Новый бриф — это новый пример.

## Шаги
1. Скопируйте шаблон:
   ```bash
   cp -r examples/demo-template examples/megafon
   ```
2. Откройте `examples/megafon/brief.md` и вставьте в раздел «Запрос руководителя (дословно)» текст задачи из брифа МегаФона. Остальные разделы можно не заполнять — агент заполнит их на этапе постановки задачи и спросит недостающее.
3. Если к брифу приложены материалы (документы, таблицы), положите их в `examples/megafon/sources/`. Только открытые данные.
4. Откройте папку в Claude Code (или Cursor) и напишите:
   ```
   начни по примеру examples/megafon
   ```
   Агент выполнит `python3 sf.py new megafon --title "<тема>" --from examples/megafon` и начнёт этап 0.
5. Проходите ворота, отвечая на вопросы агента. Прервать можно в любой момент словом «стоп», продолжить — «продолжи» (в том числе в новом чате).
6. После завершения: `python3 sf.py cost report` — время и стоимость для описания работы; `python3 sf.py validate --final` — проверка формы.

## Что не нужно менять
`AGENTS.md`, `skills/`, `agents/`, `sflib/`, `config.toml` — агент общий для любых задач.

## Проверено
Временный демо-проект `projects/demo-antifraud` создан именно этой процедурой из `examples/demo`.
