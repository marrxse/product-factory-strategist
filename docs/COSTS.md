# Время и стоимость

## Как считается
| Метод (`cost.csv → method`) | Откуда | Когда |
|---|---|---|
| **факт** | `usage` каждого ответа модели из транскрипта Claude Code (`~/.claude/projects/…/*.jsonl` и транскрипты субагентов), переносит хук Stop/SubagentStop | Claude Code |
| **оценка** | символы входа и выхода ÷ `chars_per_token` (`config.toml`) | Cursor и среды без учёта токенов |
| **время** | метки `STAGE start/done` в журнале — работа агента; `sf.py cost human` — время человека на воротах | всегда |

- Деньги — **API-эквивалент**: токены × цены Anthropic API (`config.toml [prices]`, данные на 2026-10-06; запись в кэш 5 мин = 1,25 × вход, 1 ч = 2 × вход — стандартные множители). При подписке Claude Code реальные списания иные.
- Один ответ модели пишется в транскрипт 2–3 раза; учёт берёт ответ один раз по id (иначе стоимость завышалась бы примерно в 2,4 раза — найдено при разработке).
- Факт и оценка никогда не складываются в одно число.

## Где деньги
За всю разработку (сборка агента, оба прогона, сравнение, документация и доработки) — 74,03 $ по журналам обоих проектов на 2026-11-05; на момент первого подсчёта было 37,62 $, и разбивка ниже сделана для него. Больше половины (≈20,7 $) — **чтение кэша** оркестратором (длинный контекст на Opus): 103 млн токенов чтения кэша при 0,37 млн выходных. Субагенты дешёвые: 81 ответ Haiku/Sonnet ≈ 1,3 $, Opus-критики ≈ 2,7 $.

**Как удешевить:** запускать новый чат на каждый проект (короче контекст — дешевле чтение кэша; `продолжи` восстанавливает состояние из файлов); оркестратор на Sonnet (в 2 раза дешевле по входу и выходу; цена чтения кэша такая же); один цикл проверки вместо двух, если первый дал «нет» = 0.

## Калибровка оценки для Cursor
`chars_per_token = 3.0` в `config.toml` — **не откалиброван** (значение по умолчанию). Калибровка: `sf.py cost calibrate --chars-in <символы этапа> --tokens <факт из cost.csv>`, затем записать коэффициент сюда и в `config.toml`. До калибровки оценки в Cursor давайте диапазоном ±40%.
