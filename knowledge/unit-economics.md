# Юнит-экономика: связь пользы с деньгами

## Базовая модель на одного пользователя
- **LTV** ≈ ARPU за период × маржинальность × ожидаемое число периодов жизни (≈ 1 / отток за период).
- **CAC** — затраты на привлечение одного пользователя (маркетинг + продажи + бонусы) за период ÷ число новых.
- Условие здоровья: LTV > CAC с запасом; срок окупаемости CAC меньше горизонта решения.
- Для подписки: выручка когорты по месяцам (не средняя по всем).

## Как писать в стратегии
1. Цепочка: польза → поведение (что люди будут делать иначе) → метрика → деньги.
2. Каждое число с меткой; прогнозы — диапазоном: `ARPU 150–220 ₽/мес [ПРОГНОЗ E6]`.
3. Чувствительность: какая переменная сильнее всего меняет итог (обычно отток и конверсия в оплату).
4. Затраты: разработка, поддержка, привлечение, партнёрские отчисления, каннибализация других продуктов.
5. Нет данных — так и напиши: «Не знаем стоимости привлечения в канале X; для решения нужна оценка ±30%; закрыть пилотом за 2 недели».

## Ловушки
- Средний ARPU по всей базе для нового сегмента.
- Игнорирование каннибализации: пользователь перешёл с платной функции на новую.
- «Бесплатный» канал (свои пуши/SMS) — у него есть цена: усталость базы и отписки.
