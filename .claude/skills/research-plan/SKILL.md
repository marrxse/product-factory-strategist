# План исследования (этап 2)

## Шаги
1. `python3 sf.py stage 2 start`.
2. Выпиши решение из брифа и варианты, между которыми оно выбирает (черновик, не финал).
3. Для каждого варианта спроси: «Что должно быть правдой, чтобы он был лучшим?» Каждое такое условие — вопрос исследования.
4. Оцени каждый вопрос: цена ошибки (1–3) × неопределённость сейчас (1–3). Порядок — по произведению. Вопросы с баллом 1–2 не исследуем, перечисляем как осознанно отложенные.
5. Для каждого вопроса: метод (кабинетное исследование, анализ таблицы, разбор интерфейса, гайд интервью, синтетические респонденты только для гипотез), источники из `evidence.csv` или что ещё найти, критерий ответа.
6. Бюджет: ориентир по стоимости модели и времени на этап 3 (`python3 sf.py cost report` показывает, сколько уже потрачено).
7. Запиши `outputs/research-plan.md`:
   ```
   # План исследования
   ## Решение и варианты
   ## Вопросы, способные изменить решение
   | № | Вопрос | Цена ошибки | Неопределённость | Метод | Источники | Чем ответим |
   ## Отложено осознанно
   ## Бюджет и сроки
   ```
8. `python3 sf.py stage 2 done` → покажи 3–5 главных вопросов и бюджет, спроси подтверждение.

## Чего не делать
- Не составляй список «всё про рынок». Вопрос, ответ на который не меняет выбор, — лишний.
- Не планируй синтетических респондентов как доказательство спроса.
