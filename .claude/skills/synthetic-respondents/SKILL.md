# Синтетические респонденты (только для гипотез)

## Когда полезно
До реальных интервью: найти варианты барьеров, формулировок и сценариев, которые стоит проверить; проверить гайд на наводящие вопросы. Не замена исследования.

## Шаги
1. Персоны (3–5) из данных исследования, а не из фантазии: каждая черта со ссылкой `[E…]` или пометкой `[ГИП]`. Обязательно одна «трудная» персона: скептик или пользователь конкурента.
2. Для каждой персоны вызови субагента `respondent` с описанием персоны и гайдом из `interview-guide`. Он не видит наших гипотез и вариантов: так меньше подыгрывания.
3. Сохрани беседу в `sources/synthetic-<персона>.md` с заголовком «СИНТЕТИКА — не данные о реальных людях».
4. Значимые реплики: `sf.py evidence add --kind synthetic --source sources/synthetic-<персона>.md --quote "…" --quality C` → получат id `S…`.
5. В outputs только так: `Возможный барьер: страх скрытых платежей [СИНТ S3] → проверить в интервью, вопрос 4.`
6. Итог — раздел «Гипотезы из синтетических бесед» в `research.md`: гипотеза → как проверить на реальных людях.

## Синтетическая фокус-группа (десятки персон)
Когда нужно найти возражения к конкретному предложению (сообщение, экран, цена) — не 3–5 бесед, а 40–100 коротких реакций. Методика — `sf.py kb фокус-группа`.
1. `state/focus/spec.toml`: предложение ровно в том виде, как его увидит человек; коды стоп-факторов; сегменты с долями и признаками из исследования (ссылки в комментариях).
2. `sf.py focus setup` — персоны создаёт код по зерну, задания пачками по 10 в `state/focus/batch-*.md`.
3. Каждую пачку — отдельному субагенту `respondent`; его строки JSON дословно в `state/focus/responses.jsonl`.
4. `sf.py focus map` — карта стоп-факторов «×N из M персон» по сегментам, цитаты, условия, неверные пересказы.
5. В реестр — 3–6 записей `S…` с главными возражениями; в стратегию — таблица «стоп-фактор → что меняем» с метками `[СИНТ S…]` и вывод только `[ГИП]`. Доля «купят / не купят» не считается и не пишется.

## Жёсткие запреты (validate проверяет)
- S-ссылка без метки `[СИНТ …]`.
- Вывод `**C…**` на синтетике, если он не помечен `[ГИП]`.
- Синтетика рядом со словами «спрос», «большинство», «готовы платить», «распространено», «купят», «вердикт».
