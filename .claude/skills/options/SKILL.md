# Варианты (этап 4)

## Шаги
1. `python3 sf.py stage 4 start`.
2. Набери варианты по разным осям, а не оттенки одной идеи: оставить как есть · закрыть направление · минимальное изменение · смена аудитории · смена ценности или модели дохода · **другой плательщик** (бизнес, партнёр, B2B2C вместо пользователя) · крупная ставка. Обычно 4–6 вариантов.
   Горизонт рекомендации — весь период из брифа: если просили «на год», дай последовательность решений с развилками, а не только первый квартал.
3. Тест различия: для каждой пары вариантов назови разницу ставки — кому, что, зачем. Если разница только в формулировке, объедини варианты.
4. Для каждого варианта заполни блоки (заголовки обязательны, их проверяет validate):
   ```
   ## Вариант A — оставить как есть
   Ставка: кому, что, зачем.
   Что получаем / цена: затраты, доходы, сроки — с метками [E…]/[ПРОГНОЗ …]/[ГИП].
   Риски.
   Сильнейшее возражение: …
   Что должно оказаться истинным: …
   ```
5. Возражения: передай субагенту `critic` только `brief.md`, `outputs/research.md`, черновик `options.md` и `evidence.csv`, без истории рассуждений. Вставь его сильнейшее возражение по каждому варианту дословно, свои ответы на него — отдельно.
   Параллельно — субагент `board` (совет взглядов: финансовый директор, маркетинг, юрист, поддержка, голос клиента) с теми же входами: голоса «за / против / при условии» по каждому варианту. В `options.md` — раздел «Совет взглядов»: где роли расходятся сильнее всего и условия, повторяющиеся у нескольких ролей (кандидаты в пороги плана проверки). Победителя по голосам не называй — решает человек на воротах 4.
6. Матрица сравнения: варианты × критерии из брифа (оценка 1–3 + основание). Методика — `knowledge/` (sf.py kb «матрица»).
7. Рекомендация: `**Cn.** Рекомендуем вариант X, потому что … [C…; E…]` и «Что бы нас переубедило»: факты, при которых выбрали бы другой вариант. Не получается назвать — вывод слабый, переработай.
8. `quality-review` → `outputs/quality-report.md`.
9. `python3 sf.py stage 4 done` → покажи человеку: варианты одной строкой каждый, рекомендацию, отчёт о качестве, «5 вопросов ревьюера». Попроси выбрать или скорректировать.

## Чего не делать
- Не делай «соломенные» варианты, чтобы рекомендуемый выглядел лучше. Возражение к рекомендуемому должно быть самым сильным, а не самым слабым.
- «Закрыть направление» — настоящий вариант с расчётом высвобождаемых ресурсов, а не формальность.
