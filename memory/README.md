# Память между проектами

`memory.csv` — то, что стоит помнить между проектами и сессиями: решения и предпочтения человека, уроки процесса, наблюдения агента.

- Запись агента — это **наблюдение агента от даты на основании …**, а не факт. В новых выводах её нельзя цитировать как доказательство: факт нужно заново подтвердить источником в `evidence.csv` проекта.
- Записи не удаляются: исправление создаёт новую запись, старая помечается «исправлена» со ссылкой; отзыв — «отозвана» с причиной.

Команды:
```bash
python3 sf.py memory add "текст" --basis "demo/C2, E5" --kind "наблюдение агента"
python3 sf.py memory search "удержание"
python3 sf.py memory correct M3 "новый текст" --reason "почему"
python3 sf.py memory revoke M3 --reason "почему"
python3 sf.py memory list [--all]
```
