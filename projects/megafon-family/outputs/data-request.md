# Запрос внутренних данных: что заменит допущения фактами

Бриф даёт таблицу итогов, но не даёт частот причин, историй клиентов и разбивки по каналам [E21; E22]. Поэтому все входы расчётов, кроме таблицы, — допущения агента [ГИП]. Ниже перечислено, какие выгрузки их заменят.

Выгрузки нужны **только в виде агрегатов**: без персональных данных и без содержания переписки и звонков. Порядок работы с выгрузкой:
1. Файл попадает в `sources/`.
2. Агент записывает его в реестр.
3. Меняет константу в `state/analysis/model.py` или `forecast.py`.
4. `sf.py revisit` показывает выводы, которые надо пересчитать.
