# О таблице cohorts.csv

**Учебный набор данных, сгенерированный для примера** (`random.seed(7)`), — не реальные данные какой-либо компании.
Играет роль «собственной таблицы руководителя продукта». В ней намеренно оставлены типичные проблемы: пропуск, дубль строки, незавершённая когорта.

Колонки: месяц когорты; установки; старты пробного периода (7 дней); оплаты после пробного периода; активные платящие во втором месяце; повторная выгрузка того же показателя; цена подписки, ₽/мес.
